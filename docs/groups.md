# Groups
Stuff I want in place so I can mess around with access and see what changes.

## Planned groups

### trusted
People/devices I actually trust.

### untrusted
People/devices I’m pretending not to trust so I can break things.

### lab-admins
Me, basically. Maybe one other person if I feel generous.

### observers
Read-only folks so I can see what “bare minimum access” actually looks like.

## What I’m planning to poke at
- how vaults show up differently per group
- how permissions stack or don’t
- how policies hit each group
- how trust/untrust changes the login flow
- how SCIM handles group assignment
